# Пакет промптов для генерации синтетического датасета дефектов талевого каната

## Как использовать
1. Копируй один промпт целиком в Nano Banana Pro / Gemini Image.
2. Генерируй 1 изображение на 1 промпт.
3. Если результат хороший — сохраняй. Если плохой — просто запускай тот же промпт еще раз.
4. Для класса `normal` рамки bbox не нужны, но нужны пустые `.txt` файлы разметки.
5. Для классов дефектов делай bbox вокруг одного основного дефекта.

## Рекомендуемая схема
- broken_wire: 25 изображений
- corrosion: 25 изображений
- kink_or_bend: 25 изображений
- normal: 25 изображений
- Итого: 100 изображений

## Именование файлов
Сохраняй изображения по шаблону `class_XXX.jpg`, например `broken_wire_001.jpg`, `corrosion_014.jpg`, `normal_025.jpg`.
